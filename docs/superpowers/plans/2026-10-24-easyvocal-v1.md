# EasyVocal v1 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** A free, lightweight Windows tray app that applies classic voice filters to the microphone in real time, mixes a customizable soundboard into it, and sends the result to the VB-CABLE virtual microphone so any call app hears it.

**Architecture:** A UI-free class library (`EasyVocal.Core`) holds the data model, settings storage, all DSP (effects, voice shifter, chain, limiter), the soundboard mixer, format conversion, the audio engine (behind input/output interfaces, so it is tested with fakes) and hotkey logic. A WPF app (`EasyVocal`) holds the NAudio WASAPI device implementations, Win32 global hotkeys, the tray icon and every window. Audio runs at a fixed 48 kHz mono float pipeline in 10 ms blocks.

**Tech Stack:** C# 12 / .NET 8 (`net8.0-windows`), WPF, NAudio 2.2.x (MIT) + NAudio.Vorbis (MIT) for OGG, System.Windows.Forms only for `NotifyIcon`, xUnit for tests.

**Spec:** `docs/superpowers/specs/2026-10-24-easyvocal-design.md`

## Global Constraints

- Windows 10/11 only; `net8.0-windows`; self-contained win-x64 release, **download under ~80 MB**.
- Free, MIT, no ads, no nags, nothing locked. Public repo — no secrets, no personal paths.
- No real celebrity/character voice models and no recognisable meme clips shipped; starter sounds are **generated by our code** (no license question at all).
- Added latency target: **under ~50 ms end-to-end** with classic filters (DSP budget ≤ 30 ms; WASAPI buffers ≤ 20 ms).
- OFF or the "Normal" voice = the clean voice still reaches the virtual mic.
- The voice only reaches the call while the app runs; no background service in v1.
- UI text in English through `L.T("…")`; Brazilian Portuguese (`pt-BR`) shipped complete. Code, comments, commits in English.
- Dark theme by default; visible text contrast ≥ 4.5:1.
- Custom filters: about 6–8 sliders with friendly names, **no units, no dB/Hz**. Our set: Deeper↔Higher, Voice body, Robot, Echo, Old radio, Distortion, Whisper.
- Data in `%APPDATA%\EasyVocal\` (`settings.json`, `Sounds\`); unknown/missing keys get defaults.
- Dependencies: only small, permissively licensed packages (NAudio, NAudio.Vorbis, xUnit in tests).
- Audio thread: no allocation per block, no locks held while doing DSP, no LINQ.
- Sources are UTF-8 without BOM (emoji in UI). Never rewrite files with PowerShell `Get-Content | Set-Content`.
- Commit at the end of each task; do **not** push or create the GitHub repo/release until the owner asks (Task 11 prepares it).

## Review Focus

1. **The mic is unplugged, or Windows switches devices, mid-call** → no crash; the top bar says "Microphone disconnected" and the engine recovers by itself when it comes back (Task 6: `MicLost_ThenRecover`).
2. **The person picks "CABLE Output" as their microphone** (feedback loop: their own output fed back in, howling) → refused, with a sentence explaining why; the default mic never picks it (Task 6: `DefaultMic_SkipsVirtualCable`).
3. **A corrupt, unsupported or very long audio file is added as a sound** → friendly message, nothing added, no crash; files over 10 minutes refused (Task 5: `Load_CorruptFile_Throws…`, `Load_TooLong_Throws…`).
4. **`settings.json` is corrupt or half-written** (PC turned off while saving) → app opens with defaults, the bad file kept as `settings.json.bad`; saves are atomic (Task 1: `Load_CorruptFile_…`, `Save_IsAtomic…`).
5. **Voice + several loud sounds at once** → never clips harshly on the call; a limiter keeps every sample in [-1, 1] (Task 4: `Limiter_KeepsPeaksBelowOne`, Task 6: `Engine_LoudMix_NeverExceedsOne`).

Also pinned: hotkey already used by another app or another button (Task 7), running EasyVocal twice (Task 8: single instance).

**Interfaces:**

  - `static class AudioFormat { const int SampleRate = 48000; const int BlockSize = 480; }`

  - `EchoEffect(int sampleRate)`, `RadioEffect(int sampleRate)`, `DistortionEffect(int sampleRate)`, `RobotEffect(int sampleRate)`, `WhisperEffect(int sampleRate)`; each `: IAudioEffect` with `double Amount { get; set; }` (0..1). **Amount 0 = the buffer is left untouched** (early return).
  - Test helpers: `Signals.Sine(double hz, double seconds, float amp = 0.5f)`, `Signals.PulseVowel(double f0, double[] formants, double seconds)` (impulse train through 2-pole resonators), `Signals.Noise(double seconds, float amp, int seed)`, `Signals.Silence(double seconds)`, `Signals.Magnitude(float[] x, double hz)` (Goertzel), `Signals.EstimatePitch(float[] x)` (autocorrelation, 60–1000 Hz), `Signals.Centroid(float[] x, double lo, double hi)` (FFT spectral centroid), `Signals.Peak(float[] x)`, `Signals.Rms(float[] x)`. Process helpers in tests feed signals in `BlockSize` blocks.

Effect meanings (what the person hears; algorithm details are the builder's):
- **Echo**: feedback delay (~180–300 ms) plus a short room reverb; Amount raises wet mix and feedback (feedback ≤ 0.6).
- **Old radio**: band-pass ~300–3400 Hz, mild saturation, faint crackle **gated by the voice envelope** (no hiss in silence).
- **Distortion**: soft clip (`tanh` with drive from Amount), output level-compensated.
- **Robot**: ring modulation (carrier ~30–80 Hz scaled by Amount) mixed with a short comb for metallic tone.
- **Whisper**: replace the voice by noise shaped by the voice's spectral envelope (e.g. noise through a filterbank following band energies), mixed by Amount; envelope-gated.

### Task 3: Voice shifter (pitch and voice body)

**Files:**
- Create: `src/EasyVocal.Core/Dsp/VoiceShifter.cs`, `tests/EasyVocal.Tests/VoiceShifterTests.cs`

**Interfaces:**
- Consumes: `IAudioEffect`, `AudioFormat`, test `Signals`.
- Produces: `sealed class VoiceShifter : IAudioEffect { VoiceShifter(int sampleRate); double PitchSemitones { get; set; } /*-12..12*/; double FormantFactor { get; set; } /*0.75..1.33*/; int LatencySamples { get; } }`

Approach (pinned, because the tests alone don't force it): **TD-PSOLA** — track F0 per ~10 ms hop (YIN or normalized autocorrelation, 70–600 Hz, with a voiced/unvoiced decision); take two-period Hann grains centred on pitch marks; place them at spacing `period / pitchRatio`; **resample each grain by `FormantFactor`** before overlap-add so formants move independently of pitch. Unvoiced frames: grains at a fixed 10 ms spacing (no tonal artifacts on "s"/"f"). `LatencySamples` must be ≤ 30 ms (1440 samples). Ring buffers preallocated.
